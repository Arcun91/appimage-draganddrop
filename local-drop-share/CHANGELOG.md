# Changelog

## 1.0.0 (2026-09-28)
- Prima versione per Home Assistant Add-on.
- Supporto Ingress con Web UI dark mode e drag-and-drop.
- Supporto selezione file locali da `/share` e `/media`.
- Generazione QR Code SVG vettoriale ultra-veloce senza uso intensivo di CPU.
- Server di download multi-thread separato con supporto a Range Requests (HTTP 206).
- Architettura ultra-leggera (< 30 MB RAM, 0% CPU in idle).
- Supporto multi-architettura: `aarch64`, `amd64`, `armv7`, `armhf`, `i386`.
